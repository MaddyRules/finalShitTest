# Blink для ATtiny13

Светодиод на PB0 горит 500 мс и гаснет на 500 мс. Подключите анод
через резистор 330 Ом к PB0 (вывод 5 корпуса DIP-8), катод к GND.
Частота по умолчанию 1,2 МГц соответствует внутреннему генератору
9,6 МГц с заводским делителем на 8.

## Сборка

Установите `make`, `gcc-avr`, `avr-libc` и `binutils-avr`, затем
выполните `make`. В репозитории уже есть `blink.elf` для отладки
и `blink.hex` для записи во флеш-память.

Если фактическая частота отличается, выполните
`make -B F_CPU=<частота_в_Гц>UL`, подставив частоту в герцах.
Для записи с помощью USBasp выполните:

```sh
avrdude -c usbasp -p t13 -U flash:w:blink.hex:i
```
